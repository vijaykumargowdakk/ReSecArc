ReSecArc v0.5.1 is a patch release: the app starts faster, and the tools that build and test it are up to date. Nothing changes in how you draw, check or export a design, and project files are the same format (6) as in v0.5.0.

## Faster start

- The code the browser loads before the app starts is down from 571 kB to 499 kB.
- The file validator now loads only when there is something to check: opening a file or a share link, restoring unsaved work, or reading saved blocks. A first visit never downloads it.
- Autosave waits until any unsaved work has been found and offered, so it can never overwrite it.

## Quality

- 255 unit tests and 85 browser tests (Chromium, with axe accessibility checks and a 1,000-device benchmark).
- New tests: the device box height in the code matches the stylesheet, the demo design equals the validated file, and a saved block survives a reload.
- The 1,000-device benchmark runs after the other browser tests, so it no longer times out when everything runs in parallel.
- The startup size check counts every file the page loads at start, not just the first one.

## Tools

- Vite 8, Vitest 5 and `@vitejs/plugin-react` 6.
- ESLint 10 with the React hooks rules 7. Five inputs share a new `useDraft` hook, so an input never shows its old text for a moment after an undo or a change of selection.
- Dependabot now opens minor and patch npm updates only; major upgrades are done by hand, one PR per upgrade.
