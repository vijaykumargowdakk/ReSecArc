A patch release: touch support for the device palette, more accurate exports, a size limit on opened files, and React 19. There are no file format changes, so projects saved with earlier versions open as before.

## Touch screens
- Drag devices from the palette onto the canvas with a finger or a pen; a vertical swipe still scrolls the palette (#17).
- Below 900 px the palette drawer slides away while you drag, so you can drop onto the canvas under it (#51).
- The lane buttons work on tablets and stay usable when the canvas is zoomed out; they keep clear of the canvas controls (#18, #19).
- The first-run tour card no longer covers the lane buttons it points to (#52).

## Output
- The report measures device names in the browser's font before shortening them, instead of estimating from the number of characters (#40).
- In the draw.io export, protocol flows are drawn beside their links instead of on top of them (#21).

## Safety
- Open and Merge refuse a project file over 50 MB before reading it, with a clear message, and leave the current design as it was (#60).

## Under the hood
- React 19 (#36). To keep the startup bundle under its 575 kB budget, the device, link and flow editors now load the first time one is selected.
- zod 4 (#53), which clears the runtime npm audit advisory; eslint and typescript-eslint updates clear the dev-only minimatch advisories (#59). `npm audit` reports 0 vulnerabilities.
- The README has an animated demo and retaken screenshots.

## Quality
- 263 unit tests and 95 browser tests (up from 255 and 85 in v0.5.1), including axe accessibility scans in three themes, a tablet project and the 1,000-device benchmark.
